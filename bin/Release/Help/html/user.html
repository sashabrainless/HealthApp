Користувач

Редагування даних

Для редагування даних користувача в меню "Користувач" необхідно обрати "Редагувати дані", заповнити поля та зберегти зміни.


Видалення даних

Для видалення даних, в меню "Користувач" необхідно обрати "Видалити дані". Також дані можливо видалити з вікна авторизації.
